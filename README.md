## 关于

书悦是一款为长期阅读而设计的本地优先阅读器。书籍、书源与进度都留在你的设备上，界面克制、分页自然、排版讲究，没有信息流，也不打扰。

- **多格式**：EPUB / PDF / TXT / MOBI / AZW3，以及在线书源
- **书源自由**：自定义规则，把散落各处的正文聚合成一座书架
- **排版**：字号、行距、字体、页边距、主题与翻页方式均可微调
- **进度**：本地保存阅读进度、书签与书摘，支持多设备同步
- **纯净**：无广告、无推荐、无账号墙

## 下载与安装

前往 [Releases](https://github.com/zhong228/ShuYue-App/releases/latest)，每次发布同时提供两个安装包：

| 平台 | 文件 | 说明 |
|---|---|---|
| iOS / iPadOS | `ShuYue-vX.X.X.ipa` | 未签名 IPA，需使用巨魔商店 / TrollStore 或自签名工具安装；iOS 16.0 及以上 |
| Android | `ShuYue-vX.X.X.apk` | 直接安装；Android 8.0（API 26）及以上，需开启「允许安装未知来源应用」 |

> iOS 未签名包无法直接通过 App Store 安装，这是分发方式决定的，与软件本身无关。
